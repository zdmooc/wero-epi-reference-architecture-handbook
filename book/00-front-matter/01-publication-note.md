## Modèle de vérité

L'ouvrage distingue explicitement :

- **PUBLIC_VERIFIED** — fait confirmé par une source primaire ou officielle ;
- **REFERENCE_ARCHITECTURE** — architecture proposée dans l'ouvrage ;
- **INFERRED** — déduction raisonnable explicitement signalée ;
- **RUNTIME_PROVEN** — comportement démontré dans un environnement d'exécution documenté ;
- **TO_BE_VERIFIED** — point à revalider avant de le présenter comme actuel.

Une architecture de référence n'est pas une architecture de production attestée. Une preuve de lab n'est pas une preuve de production. Une architecture technique ne constitue pas une certification réglementaire.
