# Méthode de veille et mise à jour sur cinq ans

## 1. Why

A payments book becomes obsolete if it freezes:
- scheme versions ;
- regulation ;
- Wero capabilities ;
- infrastructure roles.

## 2. Watch domains

Monthly/quarterly watch:
- EPI/Wero ;
- EPC ;
- ECB/TARGET/TIPS ;
- EBA CLEARING/RT1 ;
- EU legislation ;
- ESAs/DORA ;
- Digital Euro.

## 3. Trigger types

### Major
- new rulebook ;
- law applicable ;
- new settlement model ;
- major Wero country/use case.

### Minor
- clarification ;
- reason-code update ;
- operational guidance ;
- factual correction.

## 4. Source precedence

1. legal text ;
2. scheme authority ;
3. central bank/CSM ;
4. EPI/Wero ;
5. official provider ;
6. secondary.

## 5. Change record

Every change:
- date ;
- source ;
- previous statement ;
- new statement ;
- chapters impacted ;
- diagrams impacted.

## 6. Truth labels

Maintain:
- PUBLIC_VERIFIED ;
- REFERENCE_ARCHITECTURE ;
- INFERRED ;
- RUNTIME_PROVEN ;
- TO_BE_VERIFIED.

## 7. Annual edition

Before major edition:
- recheck every CURRENT source ;
- recheck legal status ;
- recheck scheme version ;
- recheck product availability ;
- run link check ;
- update diagrams ;
- update glossary/index.

## 8. Deprecation

Historical fact may remain if clearly dated.

Example:
- old rulebook kept in version history, not described as current.

## 9. Diagram versioning

Figure metadata:
- truth level ;
- last verified ;
- sources ;
- related chapter.

## 10. Lab evidence

Lab versions:
- environment ;
- commit ;
- runtime version ;
- test ;
- result ;
- limitation.

## 11. Reader-facing edition note

Every edition should state:
- baseline date ;
- major standards ;
- known upcoming changes ;
- next planned review.

## 12. Corrections

Critical factual error:
- fix source immediately ;
- changelog ;
- issue erratum if published.

## 13. Commercial edition

A new commercial edition is justified by material changes, not arbitrary yearly renaming.

## 14. Archive

Retain:
- PDF/EPUB release ;
- Git tag ;
- source snapshot ;
- source registry ;
- changelog.

## 15. Goal

Keep the book useful for five years without pretending that volatile payment infrastructure is timeless.
