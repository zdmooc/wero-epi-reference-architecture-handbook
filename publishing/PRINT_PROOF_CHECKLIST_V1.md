# Print Proof Checklist — V1.0

**Status:** PREPARED / NOT YET EXECUTED

## Purpose

Validate the physical edition without changing the technical manuscript.

## Format decision

- [ ] trim size selected
- [ ] binding selected
- [ ] colour vs greyscale interior decided
- [ ] paper stock decided
- [ ] bleed/margins validated with printer specification
- [ ] spine width calculated from final printer/paper combination

Current guidance from the handbook strategy:
- prefer a large professional format;
- prioritize diagram readability over compactness;
- do not reduce the book merely to hit an arbitrary page count.

## Cover proof

- [ ] front cover title/subtitle readable at thumbnail and physical size
- [ ] author name correct
- [ ] no implication of official EPI/Wero sponsorship
- [ ] spine title readable
- [ ] back-cover copy checked
- [ ] barcode/ISBN area handled only if ISBN is chosen

## Interior proof

Inspect physically:

- [ ] title page
- [ ] imprint/legal page
- [ ] table of contents
- [ ] preface
- [ ] start of every major part
- [ ] all 8 hero figures
- [ ] representative secondary figures
- [ ] wide network diagrams
- [ ] ISO 20022 message diagrams
- [ ] tables with long cells
- [ ] code/XML blocks
- [ ] glossary
- [ ] acronym index
- [ ] subject index
- [ ] annexes
- [ ] final page

## Figure-specific proof

For each printed figure:
- [ ] text readable without magnification
- [ ] colour contrast acceptable
- [ ] greyscale fallback understandable where applicable
- [ ] no clipping
- [ ] caption remains with figure
- [ ] truth/source/date note readable
- [ ] line weights survive printing

## Pagination / binding

- [ ] no content lost in gutter
- [ ] hero figures not trapped in gutter
- [ ] no unintended blank pages
- [ ] chapter openings acceptable
- [ ] page numbers visible and correct
- [ ] headers/footers consistent
