# Publishing Strategy

## Product

A professional living reference handbook, not a static one-off book.

Working title:

**Wero & EPI — Architecture de Référence des Paiements Européens**

Working subtitle:

**Paiements instantanés, ISO 20022, SCT Inst, TIPS, RT1, réseaux, cloud, sécurité, résilience et réglementation européenne**

## Page count

No fixed target.

The publication is complete when the reference scope is complete. Page count is an output of editorial quality, diagrams and depth.

## Editions

Potential product line:

- digital PDF ;
- print paperback ;
- professional colour hardback ;
- EPUB where diagram readability can be preserved.

The professional edition should prioritize diagram readability over compact trim size.

## Layout principle

The book is architecture-heavy. It needs:

- generous page width ;
- readable network diagrams ;
- sequence diagrams that do not require zooming ;
- vector diagrams ;
- high-resolution print assets ;
- tables that remain readable in print.

Final trim size will be validated with a physical proof before publication. A large professional format is preferred over a small trade-book format.

## Visual density

Target is not a fixed number of diagrams, but the book should be strongly visual.

Expected families:
- context ;
- functional ;
- sequence ;
- state ;
- application ;
- network ;
- physical ;
- payment rails ;
- liquidity ;
- security ;
- resilience ;
- regulatory mappings.

## Versioning

Print:
- annual or major-edition releases.

Digital:
- minor updates when material changes occur.

Repository:
- source of truth for all editions.

## Five-year maintenance

Every major release:
1. revalidate public EPI/Wero capabilities ;
2. revalidate EPC scheme rules ;
3. revalidate TIPS / RT1 / relevant CSM documentation ;
4. revalidate EU regulations ;
5. revalidate DORA RTS/ITS ;
6. refresh diagrams ;
7. update changelog ;
8. regenerate PDF/EPUB ;
9. archive the previous edition.

## Commercial positioning

The value proposition must come from:
- end-to-end architecture depth ;
- original diagrams ;
- ISO 20022 examples ;
- network and rail views ;
- resilience scenarios ;
- reusable checklists ;
- professional reference architectures ;
- companion executable lab.

Price is decided only after print cost, edition format and final content are known.
